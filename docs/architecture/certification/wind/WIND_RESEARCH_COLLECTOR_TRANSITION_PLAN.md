- **Environment:** a dedicated research venv outside the cache and the repo (built from the runtime and research requirements with a recorded lock); the collector runs from a pinned detached checkout of the merged repository.
- **Cutover (zero missed cycles):** inside the quiet window (:31–:19): confirm the cycle finished → terminate the old loop (it is sleeping) → final incremental snapshot → hash-verified seed of `active/` → start the new loop → verify one full :20 cycle (≈228 samples, same error pattern) → verify the old path receives no writes → update the manifests. Rollback: terminate the new loop and restart the old one with its recorded command while the old worktree, venv and output still exist. Retirement only after ≥ 48 stable cycles, a verified snapshot of `active/`, and approval.
- **Growth:** ≈130 MB/day (≈47 GB/yr); a closed-day backup and local retention policy is required before the disk passes ~70 %.
